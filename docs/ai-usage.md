# AI and tool usage

Author and project owner: Arga Bona Simarmata.

An OpenAI coding assistant helped analyze the brief and references, develop the architecture and implementation, prepare synthetic fixtures, write tests, and revise documentation. Ollama with qwen2.5:1.5b was used for limited local extraction checks. Python, pypdf, and jsonschema provide document reading and contract validation.

The default demo uses explicitly labeled simulated model responses. Its evaluation measures workflow behavior, not real-model accuracy. Sample candidates and review receipts are synthetic. AI assistance and passing tests do not establish that extracted facts are correct; limitations and observed failures are recorded in verification.md.
